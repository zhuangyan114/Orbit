# Timeline tooltip 修复计划

## 问题
用户原始需求：Timeline 鼠标悬停时显示当前 Y 轴数值（不是最新采样值）。
之前实现时误删了 canvas crosshair 竖线（小虚线），导致只剩浮动小框。

## 需要恢复的内容
`src/webview/timeline/app.tsx` 的 `draw()` 函数中，在 `ctx.restore()` 之后、legend 之前，恢复 crosshair 绘制代码：

```javascript
// -- crosshair (mouse hover) --
if (mousePos) {
  const cx = mousePos.x;
  if (cx >= margin.left && cx <= margin.left + plotW) {
    ctx.save();
    ctx.strokeStyle = 'rgba(255,255,255,0.6)';
    ctx.lineWidth = 1;
    ctx.setLineDash([4, 3]);
    ctx.beginPath();
    ctx.moveTo(cx, margin.top);
    ctx.lineTo(cx, margin.top + plotH);
    ctx.stroke();
    ctx.restore();
  }
}
```

## 保留的内容
- 跟随鼠标的浮动 tooltip div（已经在 JSX 中）
- `draw` 依赖数组中的 `mousePos`（确保 crosshair 随鼠标重绘）

## 验证
1. `npm run build` 通过
2. 鼠标移入 canvas 时：同时出现 crosshair 虚线 + 浮动小框
3. 浮动小框显示 Y 轴数值（已有 relY 计算逻辑）
4. 鼠标移出时两者都消失
